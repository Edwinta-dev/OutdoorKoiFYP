# Camera colour-card reader

The camera service can now store an optional pH Alert and Ammonia Alert colour-card observation beside an uploaded frame. It only runs when the pond has saved card-mask placements (migration `0032_camera_card_masks.sql`). The method samples the moved template points with small frame-scaled square patches, white-balances each card against `white_ref`, rejects glare and inconsistent dots, then compares CIELAB chroma (`a*`, `b*`) against the printed reference segments. The ratio of the runner-up chroma distance to the best distance labels confidence as clear above 2, weak above 1.3, and ambiguous otherwise.

The sample spots are drawn from saved card-mask template points, not a fixed camera mount. Individual dots are excluded if their square falls outside the image, if more than 20% of its pixels exceed 1.1 times the white-reference luminance, or if the dot differs from its patch's median by more than 25% of the median RGB magnitude. Each patch records its median RGB and used/total dot counts. A frame is marked `unusable` below half of all dots.

The result is an image-linked row in `camera_card_readings`. `GET /v1/ponds/{pond}/camera/card-reading` returns the latest result; adding `?image_id=N` selects one frame. The camera's `POST /upload` JSON is unchanged. The offline replay entry point is `python -m koi.camera.card_reader <frames dir> --pond N`; when the directory contains `pond_N_card_masks.json` with the saved `placements` and `version`, it uses those placements. `--reference-frame path` or that JSON's optional `reference_frame` selects the clear-water reference. Without it replay emits the index-unavailable reason and disagreement state. It never contacts services.

## Turbidity and two-pipeline agreement (issue #152)

When the saved card-mask configuration names a clear-water reference image, the reader compares the current frame's usable patch medians with the same named patches saved for that image. For each RGB channel, least squares fits `observed = a * clear + b`; the result stores `a`, `b`, per-channel R² and the number of paired patches. At least 6 usable pairs are required. Any channel with `a < 0.05` makes the index unavailable because correction would amplify noise excessively. With `W` equal to the reference white patch channel value, each channel index is `b / (a * W + b)`. The overall index is the Rec. 709 luminance-weighted sum (weights 0.2126, 0.7152, 0.0722). A frame compared with itself has index zero when its fit has no scatter offset.

The same fit corrects each disc as `(observed - b) / a`, clipped to the RGB display range. The existing in-frame classification is compared with a second classification of the corrected disc against the clear-frame reference segments. `agreement` reports the boolean result for pH and ammonia; `frame_agreement` is `clear` only when both are true. Missing reference, insufficient patch pairs, or transmission below the minimum reports a null index and a reason. Replay includes channel indices and the weighted index; the card-reading GET stores the weighted index plus channel indices, fit coefficients, R² and agreement.

Three accepted camera frames in a row with card quality `unusable` enqueue one info notification that the cards may be covered or the view blocked. The row stores the streak and latch; a usable accepted frame clears both. Frame-quality rejects do not advance or clear the streak. The alert reuses the existing `camera_obstructed` outbox kind.

## Limits

This is a visual segment classifier, not a calibrated numeric pH or ammonia measurement. In the owner's reference evaluation, adjacent pH pairs seg2/seg3, seg4/seg5, and seg6/seg7 were not separable at the tested JPEG quality. Better JPEG detail and lower glare/haze are needed before treating those distinctions as reliable. A low confidence ratio reports ambiguity rather than resolving those pairs by chemistry assumptions.

The turbidity fit assumes matching printed patches are unchanged between the reference and current capture, and that one affine light-scatter model describes every patch in each channel. It is a relative optical index, not NTU. Six pairs is a minimum identifiability gate, not evidence of a statistically stable fit; the stored R² helps expose poor channel fits. Reference readings must already exist when a frame is captured, so selecting a reference image that predates #151 readings yields a no-reference result until it is re-captured as a reading.
