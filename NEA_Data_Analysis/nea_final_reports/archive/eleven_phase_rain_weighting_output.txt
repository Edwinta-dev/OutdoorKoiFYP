4. DOES A FLAT SCALAR MULTIPLIER DO ANYTHING?
========================================================================================================
  x1.0 at fixed threshold 0.25 -> fires  1695 days, precision 0.293
  x0.8 at fixed threshold 0.25 -> fires    54 days, precision 0.537
  x0.6 at fixed threshold 0.25 -> fires    54 days, precision 0.537
  x0.4 at fixed threshold 0.25 -> fires 0 days

  Multiplying every score by the same constant preserves their ORDER,
  so it cannot change which days rank above which. Against a fixed
  threshold it is exactly equivalent to raising that threshold, and it
  moves in discrete jumps as whole tiers cross the line. It is a
  threshold in disguise -- so tune the threshold, and read its cost
  ratio off the table above.
